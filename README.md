# قلمي — تطبيق تعليمي للسنة الأولى ابتدائي (المنهاج الجزائري)

مواد السنة الأولى الست: اللغة العربية، الرياضيات، التربية العلمية، التربية الإسلامية، التربية المدنية، التربية الفنية. كل الدروس بالصوت، ويعمل بلا إنترنت.

## التحميل لويندوز

1. افتح صفحة **[آخر نسخة](https://github.com/BABAHADJ26/myapp/releases/latest)** من حاسوب ويندوز.
2. اضغط على **Qalami-Setup.exe** ليُحمَّل.
3. انقر عليه نقرًا مزدوجًا. إن ظهرت رسالة «Windows protected your PC» فاضغط **More info** ثم **Run anyway**.
4. تظهر أيقونة **قلمي** على سطح المكتب.

## محتوى المستودع

- `app/` — البرنامج: الصفحة (`www/index.html`) والأصوات (`www/clips/`) والخطوط، و`main.js` الذي يشغّلها في نافذة ويندوز بلا إنترنت.
- `installer/installer.nsi` — المثبّت.
- `.github/workflows/build.yml` — يبني المثبّت تلقائيًا وينشره في صفحة Releases عند كل تحديث.
